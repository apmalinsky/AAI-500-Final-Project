# Student Performance Statistical Analysis

An exploratory and inferential statistical analysis investigating the impact of social, demographic, and academic factors on student academic performance. Developed as part of the Applied Artificial Intelligence Program at the University of San Diego (USD).

## 📊 Project Overview
This project analyzes the  ([**Student Performance dataset**](https://archive.ics.uci.edu/dataset/320/student+performance)) from the UC Irvine Machine Learning Repository (Cortez, 2008), examining survey data from 395 mathematics students and 649 Portuguese language students across 30 independent features and 3 grade periods (G1, G2, G3). 

The analysis is divided into three core evaluation tracks:
* **Social Factors (`AppendixA-SocialFactors`):** Evaluates how lifestyle, peer groups, and social habits influence final grades.
* **Demographic Factors (`AppendixB-DemographicFactors`):** Examines background indicators and family structures.
* **Academic Factors (`AppendixC-AcademicFactors`):** Analyzes historical study time, past failures, and support systems.

## 🛠️ Methods & Technologies
* **Statistical Methods:** Descriptive & Inferential Statistics, Frequency Distribution Analysis
* **Significance Testing:** Chi-Square Tests, Independent Two-Sample \(t\)-tests
* **Predictive Modeling:** Ordinary Least Squares (OLS) Regression
* **Tools:** Python, Jupyter Notebooks, Pandas, SciPy, Statsmodels

## 📂 Repository Structure
* `notebooks/`: Contains the modular Jupyter notebooks for social, demographic, and academic factor analyses.
* [Final Project Report (PDF)](https://github.com/apmalinsky/student-performance-statistical-analysis/blob/main/Final-Project-Report-Team-6.pdf): Comprehensive documentation detailing data cleaning, exploratory data analysis, statistical findings, and recommendations.
